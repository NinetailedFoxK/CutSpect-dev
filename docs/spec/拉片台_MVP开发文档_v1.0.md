## 0. 给实施 AI 的指令

你要实现一个可以安装在 macOS 和 Windows 上、离线使用的桌面拉片应用。按本文开发真实功能，不要只搭建界面原型，不要把本地导入替换成上传服务器，不要用假数据冒充完成。

实施顺序：先读全文，建立需求编号与测试的对应关系，再按第 17 节逐阶段交付。优先跑通"导入真实视频 → 编辑曲线 → 添加分析 → 保存 → 重开"闭环。每一阶段完成后，记录实际验证结果。遇到环境无法验证的项目，应标为"未验证"，不得声称已经在另一个操作系统运行成功。

本文标记为"已确认"的内容来自用户；标记为"MVP 决策"的内容是本版为减少开发分歧而制定的默认方案。不要反复要求用户确认普通实现细节；只有必须改变已确认交互、项目格式或范围时，才说明影响并询问用户。

### 0.1 用户已确认的核心要求

1. 导入一条视频，在应用内播放。
2. **红色分析曲线直接叠在视频画面上**，可以快速绘制、灵活编辑。
3. 播放器下方是类似剪辑软件的视频时间线。
4. 曲线横轴严格对应时间线；缩放、平移后继续对应。
5. 视频与曲线可以分别调节透明度，也可以分别关闭、打开。
6. 用可拖动、可锁定的竖向虚线划分部分。
7. 可以在曲线上添加黄色标注点。
8. 需要完整软件的最小可行交互，包括素材与项目管理。
9. 能在苹果和 Windows 电脑上稳定运行。

### 0.2 不允许偏离的设计

- 不把主工作区改成"上方视频、下方独立曲线图"。曲线必须覆盖视频所在画布。
- 用户草图中的紫色框、黄色框是布局示意，不要求把粗彩色边框做进正式界面。
- 调低曲线透明度不能连带调低视频；调低视频透明度不能让标注消失。
- 时间线代表原视频的时间；曲线高度表示分析值，不能改变视频播放速度或素材内容。
- 时间对应关系不能依赖屏幕像素保存；窗口变化和时间缩放后，数据位置必须保持正确。

## 1. 产品目标与最小范围

### 1.1 面向的工作

创作者分析短视频、广告、电影片段的情绪、节奏、信息密度等变化。用户自己观察并判断，用一条曲线和若干文字标注留下分析结果。

典型场景：导入一条 3 分钟的视频，先看一遍，再画情绪曲线，在开场、转折、高潮处划分段落，给几个关键时间写备注；下次打开继续修改，最后导出分析图和笔记。

### 1.2 MVP 取舍

| 事项 | 本版决策 |
|---|---|
| 应用形态 | 本地桌面应用，中文界面，离线可用 |
| 项目关系 | 一个项目包含一条视频、一条可命名曲线、多条分段线、多条标注 |
| 多视频管理 | 通过项目库管理多个项目；第一版不做全局素材仓库或项目内多素材编排 |
| 视频导入 | 从本机选择文件或拖入，复制到项目内；不上传、不修改源文件 |
| 项目保存 | 项目文件夹内保存数据与视频；支持自动保存、手动保存、恢复备份 |
| 视频能力 | 播放、暂停、拖动定位、倍速、静音；不剪辑、不渲染视频成片 |
| 曲线能力 | 自由画、节点画、直线、贝塞尔控制柄、局部重画、节点增删与多选 |
| 分析输出 | 无视频背景的 PNG 曲线图、Markdown 分析笔记 |
| 项目迁移 | 关闭后整体复制项目文件夹，在另一台电脑中打开 |
| 平台目标 | macOS 14 及以上，Apple Silicon 与 Intel；Windows 11 x64 |
| 不承诺的平台 | Windows ARM、Windows 10、更早 macOS、Linux、手机、平板、网页独立部署 |

平台范围是本版测试基线，不表示所有更早系统必定不能运行。安装包所用 Electron 版本必须仍支持这些目标系统；若实施时官方支持范围改变，应记录并调整基线，不能悄悄缩小支持范围。

### 1.3 明确暂不开发

账号、云同步、团队协作、收费系统、AI 自动分析、自动字幕、字幕编辑、自动切镜、多轨剪辑、音频波形、多条曲线对比、曲线模板市场、插件系统、视频合成导出、自动更新、片段循环播放、专门的项目压缩包格式。

不做源视频严格逐帧前后步进。第一版提供按秒定位；HTML 视频播放器不能被包装成已经支持任意编码的精确倒退一帧。

### 1.4 什么叫最小可行完成

在没有开发环境的目标电脑上安装后，用户能导入真实视频、画线、做分段和标注；关闭再打开数据仍在；整个项目复制到另一系统后可以继续编辑；遇到不兼容视频或写入失败时，能看懂问题并处理。

## 2. 信息架构与页面

软件只有两个主页面，以及必要弹窗和设置面板。

```text
启动
 └─ 项目库
     ├─ 新建项目 → 选择视频与位置 → 导入 → 分析工作台
     ├─ 最近项目 → 分析工作台
     ├─ 打开项目文件夹 → 分析工作台
     └─ 设置 / 关于

分析工作台
 ├─ 编辑曲线、分段、标注
 ├─ 导出分析图 / 分析笔记
 ├─ 项目设置 / 素材信息
 ├─ 保存 / 恢复备份
 └─ 返回项目库
```

### 2.1 首次启动

直接进入项目库空状态，显示"导入视频，开始第一次拉片"和"新建项目""打开项目文件夹"。不强制注册，不出现多页教程。

默认项目根目录建议为系统"文稿 / Documents"下的"拉片台项目"。用户可在新建时修改位置，之后记住最近选择。无法写入默认位置时，要求选择其他文件夹，不提权写入。

### 2.2 项目库（HOME）

顶部：应用名、搜索、新建项目、打开项目文件夹、设置。

项目卡片内容：视频封面、项目名、源文件名、时长、最近编辑时间、状态。默认按最近编辑降序。搜索项目名及源文件名；不做复杂标签和文件夹树。

卡片操作：打开、重命名、在文件管理器中显示、从最近列表移除。

- "从最近列表移除"只移除应用内索引，不删除磁盘上的项目或视频；操作后提供撤销提示。
- 第一版不提供项目库内"永久删除"。需要删除时在系统文件管理器中操作。
- 项目名可以重复，项目 ID 与磁盘文件夹名保证唯一。
- 项目位置消失时保留卡片，显示"项目位置已改变"，提供"重新定位项目""从列表移除"。
- 应用只记录最近项目，不擅自扫描整块硬盘。

### 2.3 新建项目弹窗（CREATE）

字段：视频文件、项目名称、保存位置。视频选择后自动带入不含扩展名的名称，可修改。

显示"视频将复制到项目文件夹，原文件保持不变"，以及源文件大小、可用空间。点击"创建并导入"后创建唯一项目文件夹。

项目名展示原文；磁盘目录过滤 Windows 禁用字符、保留名和过长名称，附加短 UUID。主文件固定叫 `project.json`，不随项目显示名改动而重命名目录。

拖入多个文件时提示"当前每个项目支持一条视频，请选择其中一个"，允许选一个，不能默默只取第一个。拖入文件夹时提示使用视频文件或"打开项目文件夹"入口。

### 2.4 导入状态（IMPORT）

步骤：检查 → 复制视频 → 读取信息 → 试播 → 准备时间线缩略图 → 可编辑。

复制显示字节进度；探测或试播无可靠百分比时显示当前步骤。缩略图后台生成，视频可播放后即可进入工作台，不必等待全部缩略图完成。

导入可取消。取消时停止当前进程并清理本次未完成临时文件，不触碰用户源视频。清理失败时记录临时路径并在下次启动重试，仅处理应用自身已登记的临时目录。

若需要转换兼容副本，先展示原因、目标格式与"可能需要较长时间"，由用户点击"生成兼容副本"；用户可以取消并返回项目库，之后重试。

复制与基础探测成功前使用临时导入目录，不登记为正常项目。基础数据和原片已完整保存、但尚待兼容处理的项目，可以登记为"待处理"；打开后进入兼容处理页，暂不启用编辑。待处理状态由素材检查结果推导，不把后台进程状态混入曲线正文。

时间线的有效起止位置与上方曲线绘图区左右边缘严格对齐。左侧工具栏、右侧属性面板占用的宽度，必须在两处共同扣除；不能让缩略图从窗口左边开始而曲线从工具栏右边开始。

窗口最小尺寸 1100×720 CSS 像素；推荐 1440×900。时间线默认高 160，可拖动到 120—280。属性面板宽 280，打开时两个时间区域一起重新布局。记录窗口尺寸、位置；多屏变化后窗口必须回到可见区域。

不强制画布固定 16:9。视频按原比例 contain 放在画布中央，竖屏保留两侧背景；曲线时间域覆盖整个绘图区，不能随视频黑边改变。

## 3. 视频、画布与时间的统一规则

### 3.1 唯一时间坐标

数据使用相对视频起点的整数毫秒。显示格式 `HH:MM:SS.mmm`，界面空间不足时省略小时。时间是媒体时钟，不按墙上时钟累计，不受播放倍速影响。

定义：

- `durationMs`：项目的标准视频时长。
- `viewStartMs`、`viewEndMs`：当前可见时间区间。
- `plotLeft`、`plotTop`、`plotWidth`、`plotHeight`：绘图区在当前视图中的几何数据。
- `value`：曲线纵向值，0—100，默认维度名"情绪强度"，可改名。

映射：

```text
x = plotLeft + (timeMs - viewStartMs) / (viewEndMs - viewStartMs) × plotWidth
timeMs = round(viewStartMs + (x - plotLeft) / plotWidth × (viewEndMs - viewStartMs))
y = plotTop + (1 - value / 100) × plotHeight
value = clamp((1 - (y - plotTop) / plotHeight) × 100, 0, 100)
```

曲线、节点、标注、分段线、时间刻度、缩略图、播放头使用同一个坐标模块。禁止各组件自行计算不同的左右 padding 或时间比例。

纵轴只有"低—高"和轻网格，不暗示数据是客观测量值。0—100 是编辑坐标；用户可以只用曲线表达相对变化。

### 3.2 播放与定位

- 视频播放器是实际播放时间的唯一来源；播放头从播放器更新，不能靠另一个计时器自行前进。
- 播放时优先使用 `requestVideoFrameCallback` 的媒体时间更新播放头；不支持时用动画帧读取媒体时间。`timeupdate` 用于补充状态，不作为唯一平滑刷新来源。[S4]
- 用户拖动时间线时立即更新预览播放头，节流提交 seek；松手后提交最终位置。异步 seek 只接受最新请求，防止旧结果把画面拉回。
- 播放中开始拖时间线会暂停，松手后保持暂停。按空格恢复。
- 节点和分段线移动只改变分析数据，不在每个指针事件触发视频解码。操作结束后定位到对象的新时间。
- 开始任何画线、拖动编辑、输入标注前自动暂停，完成后保持暂停。
- 隐藏视频或视频透明度为 0 时，媒体时钟与音频仍可工作；音频只受静音、音量和播放状态控制。
- 视频隐藏时保留媒体元素，不用卸载组件或移除 src 实现隐藏。若透明度或遮挡让帧回调停止，应回退读取媒体 currentTime，避免分析播放头停住。
- 倍速选项：0.5×、1×、1.5×、2×。时间线及分析数据不因倍速改变。
- 键盘左右键定位前后 1 秒，Shift＋左右键定位前后 5 秒；在文本框或节点已获得键盘编辑焦点时不抢占其操作。
- 点击标注后暂停并跳到标注时间，展开备注。点击段落名称后暂停并定位到段落起点。
- `timeMs=durationMs` 是合法的结构终点；播放画面实际定位到可解码的最后画面，不能因视频结束事件产生无限 seek。

### 3.3 时间缩放和平移

默认显示完整视频。缩放滑杆与"适应全部"按钮常驻；最短可见区间为 `min(1000ms, durationMs)`。视频长度不足 1 秒时全长就是最短区间。

缩放锚点优先为当前可见播放头，否则为视口中心。可见区间不得越出 `[0, durationMs]`。底部横向滚动条负责平移；Shift＋滚轮也可平移。

播放头越过可见右边界时整页向后平移，保留约 10% 的前文，不每帧移动整张曲线。用户手动平移后暂时停止自动跟随，显示"回到播放头"；点击后恢复。该跟随设置是视图状态，不修改分析数据。

缩放、平移和窗口尺寸变化只改变显示，不改变时间、曲线值、标注归属或段落。

## 4. 图层与透明度（LAYER）

固定叠放顺序：画布背景 → 视频 → 轻网格 → 分段虚线 → 红色曲线 → 黄色标注 → 临时编辑手柄与播放头。

点击"图层"展开：

| 行 | 显示开关 | 透明度 | 锁定 |
|---|---|---|---|
| 视频 | 独立 | 0—100% | 无 |
| 曲线与标注 | 独立 | 0—100% | 可锁定 |
| 标注点和文字 | 子开关 | 继承分析层 | 继承分析层 |
| 分段线和名称 | 独立 | 默认 65%，本版不单设滑杆 | 可逐条锁定 |

默认视频 100%、分析层 100%，均显示。提供一个快捷"分析视图"预设：视频 25%、分析层 100%；用户随后仍可独立调整。

视频透明度作用于 video 元素；分析透明度作用于曲线、标注和持久标签，不影响工具栏。分段线透明度不受视频透明度影响。播放头、选中轮廓、控制柄保持可见，避免无法操作。

- 隐藏开关与透明度分别保存；关闭再打开，恢复原透明度。
- 分析层隐藏或透明度为 0 时不接收命中事件，编辑工具禁用；状态栏提示"请显示曲线并提高透明度后编辑"。
- 分析层锁定后，允许点击标注查看和定位，禁止改曲线、增删标注；仍可独立编辑未锁定的分段线。
- 隐藏视频后背景为深灰；不能把整个画布隐藏。
- 返回项目后恢复上次图层配置，不能每次恢复默认。
- 分段线隐藏时不接收直接拖动；仍能从段落列表查看、重新显示。

## 5. 曲线编辑（CURVE）

### 5.1 初始曲线与数据约束

新建项目默认曲线名"情绪强度"，有两个值为 50 的端点：`0ms` 和 `durationMs`，形成水平线。首尾端点时间固定，可改高度，不能删除。小于 1ms 或没有有效视频轨的文件不可创建项目。

任意时刻只有一个曲线高度，节点时间严格递增，最小相邻时间差 1ms；禁止回环、重复时间、NaN 和越界。编辑采样及命中距离用 CSS 像素，存储使用时间和值。

### 5.2 工具与行为

| 工具 | 操作 | 完成与取消 |
|---|---|---|
| 选择 V | 点击节点选中；拖节点；拖空白框选节点；Shift 多选 | Esc 取消选择 |
| 节点 P | 在画布单击添加节点并形成自动平滑曲线；可拖节点 | 每次点击是一条撤销记录 |
| 自由画 B | 按住指针从左往右画，实时预览 | 松手提交；Esc 取消本笔 |
| 直线 L | 从起点拖到终点，替换这段曲线为直线 | 松手提交；Esc 取消 |
| 标注 M | 在曲线上点击添加标注；另有按钮在播放头添加 | 打开备注卡片 |
| 分段 S | 点击画布时间位置添加边界 | 单次操作后回选择工具 |

在节点工具点击已有节点时选择该节点，避免生成重复点。选择工具双击曲线可在该时间增加节点并尽量保持原形。点击空白不 seek；视频定位主要通过时间线，避免画线与播放抢操作。

### 5.3 选择、节点与控制柄

- 节点编辑点为浅色小方点或带描边圆点，仅在编辑时出现；黄色实心圆专用于备注。
- 拖节点同时改时间与高度；按住 Shift 只改高度，时间不变。
- 时间不能越过前后节点；到达边界时夹紧，不自动交换节点身份。
- 右键节点提供"自动平滑""编辑控制柄""下一段改为直线""删除节点"。
- 自动平滑优先使用形状保持的分段三次插值，避免原本 0—100 的节点产生超范围尖峰。
- 切换到控制柄模式时，把相邻自动段转换为等形的显式三次贝塞尔段。手柄默认独立，允许制造转折；本版不做复杂的手柄联动模式。
- 控制柄横向位置限制在所在段内，两个控制点 x 顺序必须满足 `x0 ≤ c1x ≤ c2x ≤ x1`，确保时间单调。控制点纵值限制为 0—100。
- 贝塞尔按时间求值必须反解 x，可用二分法；不能把归一化时间直接当作参数 u 后忽略非线性横向手柄。
- 双击显式贝塞尔段新增节点时使用分割算法，保持原曲线形状；自动平滑段新增点应保持在原曲线上，新增后允许其相邻自动段重新求形。
- 框选多个节点可整体拖动；时间位移按全部节点可行范围统一夹紧，不能逐个夹紧导致节点互相挤压。包含首尾端点时组的横向移动固定为 0，高度仍可整体移动至边界。
- Delete/Backspace 删除所选普通节点；首尾节点保留。控制柄跟随节点一同移动。
- 属性面板允许输入选中节点的时间与值，遵守同样约束。无效输入显示原因，不静默写入坏数据。
- 节点改变后，重新夹紧受影响段的控制柄时间和纵值，保留其相对方向并尽量减少形变；整次节点移动与伴随的手柄修正属于同一条撤销记录。删除节点后，连接段默认恢复自动平滑；撤销时恢复原节点与原手柄。

### 5.4 自由画与局部重画

自由画是对当前曲线一段时间的替换，不额外创建第二条曲线。

1. 指针按下时记录原曲线快照和起点。
2. 根据指针横向位置取时间，纵向取值；只接受向右推进的采样，向左抖动不产生回环。
3. 松手后将轨迹按时间去重、适度简化，再生成平滑段；显示尺度下简化误差目标不超过 3 CSS 像素。
4. 只替换本笔覆盖的 `[startMs, endMs]`。区间外节点保留；跨越边界的原有曲段需分割，保留区间外部分的原形。
5. 新笔迹的两端与旧线在边界处连续；预览应反映端点吸附结果。允许边界有斜率变化，不允许断开。
6. 起点或终点在视频首尾时，可直接修改对应端点高度；普通局部重画的两个边界值取原曲线值，内部可自由变化。
7. 一笔横向宽度小于 4 CSS 像素时不提交，提示"向右拖动绘制"；原曲线不变。
8. 一次完整笔迹只产生一条撤销记录。快速采样放临时状态，不能每个 pointermove 都写入项目或进入历史。

直线工具遵循同样的局部替换边界规则。先预览，松手后提交；曲线之外的标注时间保持不变，纵向位置随新曲线更新。

### 5.5 命中优先级

在选择工具下：活动控制柄 > 曲线节点 > 标注点 > 分段线顶部拖柄 > 曲线 > 空白。几何元素在画布中的命中热区约 8 CSS 像素，视觉线宽可更细。

分段线拖柄集中在顶部，避免纵向整条虚线抢走曲线节点。标注工具优先处理标注，分段工具优先处理分段；工具模式变化应有明显高亮和光标提示。

## 6. 标注（NOTE）

每条标注属于当前曲线，包含 ID、时间、标题、正文、标签偏移。其纵向位置通过曲线在该时间的值计算，不另存一份容易失真的高度。

### 6.1 创建

- 标注工具点击曲线，按点击时间添加；命中不要求精确到线中心，可吸附至该时间的曲线。
- 按 M 切换标注工具；工具栏另有"在播放头标注"按钮，直接在当前时间添加。
- 新点出现并打开小卡片，标题最多 80 字符，正文最多 5000 字符；支持换行，纯文本。
- 新标注暂存草稿；提交时标题为空而正文有内容，自动取正文首行前 20 字符作标题。两者都空则取消，不留下空点。
- Ctrl/Cmd＋Enter 完成；Esc 取消未提交的本次文字修改。点击卡片外部时有内容则提交，空草稿取消。

### 6.2 查看与修改

点击点：选中、暂停、定位视频、展开属性。拖动标注点只改时间，点始终吸附在曲线上；不改变曲线本身。可在属性中精确输入时间。

默认显示黄色点和一行简短标题；拖动文字标签仅改变标签在画布中的偏移，并显示细连接线。偏移以 CSS 像素记录，重排时夹紧在画布内。超过两行的正文只在卡片和属性面板显示。

标签重叠时优先显示选中与悬停项，其余可仅留点；至少保证右侧"标注列表"可按时间访问全部标注。列表可按标题和正文搜索。MVP 不做复杂自动排版算法。

同一毫秒只允许一个标注，重复创建则打开已有标注。右键或属性面板可删除，支持撤销。修改曲线时标注时间不动，点的纵向位置重新计算。

## 7. 分段与虚线（SECTION）

### 7.1 结构模型

视频首尾是固定边界，中间可添加用户边界。两个相邻边界之间就是一个段落；段落始终连续覆盖完整视频，不重叠、不留空。

每个段落有名称和一段纯文本备注。名称默认"段落 1、段落 2……"；创建后名称作为内容保留，不因插入前面的段落而重编号。用户可以命名为"开场钩子""铺垫""高潮"。

段落身份绑定起点边界 ID，而不是当前排序下标；移动边界时名字不能跑到别的段落。

### 7.2 增删与拖动

- 点击分段工具后在画布或时间标尺选择时间，新增竖向虚线。
- 边界添加到已有段落内部时，左段保留原名称与备注；右段创建默认名称和空备注。
- 边界间最小间隔为 100ms。小于 200ms 的视频不能再插入内部边界；近邻空间不足时提示"请放大时间线，或选择间隔至少 0.1 秒的位置"。放大只帮助定位，不能绕过时间约束。
- 拖动顶部拖柄实时改变时间，显示时间浮标；不得跨过相邻边界。松手后视频定位到边界时间。
- 移动边界不移动曲线节点或标注，不对分析数据做拉伸。
- 每条内部边界可锁定。锁定后禁止拖动、时间编辑和删除；可查看内容、解锁。
- 删除未锁定边界时合并相邻段落：保留左段名，非空备注用明确分隔合并，不能静默丢掉右段文字。操作前的小确认框说明此规则，支持撤销。
- 首尾边界不可拖动、删除或解锁。

画布顶部显示段名，时间线段落条显示同样的分区；宽度不足时截断文字，悬停显示完整名称。右侧"段落列表"显示全部段落的起止时间和备注。

## 8. 撤销、保存、退出与恢复（SAVE）

### 8.1 撤销与重做

覆盖：节点增删改、控制柄、整笔重画、直线替换、多节点移动、标注增删改、边界增删改锁定、段落文字、曲线名称。

一次拖动、一次笔迹、一轮文字编辑各是一条历史操作；连续输入可在 500ms 空闲或失焦后合并提交。保存不是历史节点，保存后仍能撤销。最多保存最近 100 条操作，重开项目不恢复历史。

播放、seek、缩放、面板折叠、图层可见性和透明度等视图操作不进入内容撤销历史，但视图状态仍自动保存。Esc 取消正在进行的手势时，恢复手势开始前状态，不创建历史。

### 8.2 保存状态

顶栏显示：已保存 / 正在保存 / 尚有更改 / 保存失败。真实持久化成功后才能显示"已保存"。每次内容提交后 1 秒防抖保存，持续编辑时最迟 5 秒保存一次；仅保存已完成操作，不保存半笔轨迹。

Ctrl/Cmd＋S 立即保存。无变化时不重复写入。禁止用 localStorage 作为项目正文的唯一存储。

媒体每帧播放时间只更新内存中的 view；暂停、定位结束、关闭项目前刷新持久化位置，连续播放时最多每 5 秒合并一次视图快照。透明度拖动也在松手后提交视图保存，避免每帧产生磁盘写入和备份。

保存使用串行队列和递增 revision，写入期间发生新编辑时，继续排队最新快照；旧请求的完成通知不能把新内容误标为已保存。每次保存先通过 schema 校验。

### 8.3 磁盘写入

在同一项目目录写临时文件 → flush 并关闭 → 替换主文件。保证替换前旧主文件可读，失败不能先删除旧文件。Windows 文件被占用时做有限重试，并保留失败快照以便重试；不要无限循环。

保留最近 5 份已确认有效的正文备份，至少间隔 60 秒生成一份；手动保存可触发备份，避免每次自动保存都迅速覆盖所有历史。备份不包含视频和缓存。

新版本 `schemaVersion` 高于当前程序时，禁止覆写，提示使用新版。升级旧格式时先备份，再迁移；迁移失败保留原文件。

### 8.4 退出与崩溃

返回项目库、切换项目、关闭窗口时先完成草稿处理和待保存队列。成功则直接退出，不做多余确认。

保存失败时弹窗："更改尚未保存"，提供"重试""保存恢复副本到其他位置""放弃本次未保存更改并退出""取消"。恢复副本为可供恢复流程读取的项目 JSON，明确它不包含视频。

正常退出只有在主文件保存完成后释放项目锁。异常退出后检测更晚且校验有效的恢复文件，展示时间、提供"恢复""使用原版本"；恢复前保留原版本。

### 8.5 单写入者

应用单实例，MVP 同时只打开一个项目。项目通过跨进程文件锁保护；锁存活时另一个进程不得写入，可提示关闭占用程序。锁依赖应支持异常终止后的失效判定，不能只靠一个永久残留的 `.lock` 文件。

不支持多台电脑同时编辑网络盘上的同一文件夹。项目可以离线迁移，正在编辑时不复制或双向同步；本版针对本地磁盘验收。

## 9. 素材管理与项目迁移（MEDIA / PROJECT）

### 9.1 为什么一个项目一条视频

本版最重要的产物是"针对一条视频的完整分析"。项目卡片就是这条素材的入口，省去全局素材库、引用计数和跨项目清理，减少视频丢失与误删除。

### 9.2 复制和路径

原视频复制进项目 `media/`；复制同时在后台流式计算完整 SHA-256，不一次性读进内存。后续播放使用项目内副本。项目中的持久路径使用相对路径与 `/` 分隔，读取时按宿主系统解析。

所有文件操作必须把真实路径限制在当前项目及用户明确选择的输出位置。拒绝项目 JSON 中的路径穿越、任意绝对路径和越界符号链接。Windows 盘符和 macOS 用户名不能写死。

用户可查看素材信息：原文件名、大小、时长、分辨率、视频/音频编码、平均帧率、当前播放的是原片还是兼容副本。提供"在文件管理器中显示""重新生成缩略图"。

### 9.3 缺失与损坏

视频缺失时仍打开项目中的曲线、标注和分段，视频区域显示缺失提示。暂停所有播放操作，但保留分析查看和笔记导出。

"重新定位视频"只接受与记录 SHA-256 一致的同一素材；验证完成后复制回项目。不同文件不能直接替换，否则原标注会错位。提示用户为新素材新建项目，本版不做重定时映射。

项目主文件损坏时不覆盖：尝试展示有效备份列表，用户选择恢复。缓存损坏则可删除该缓存并重建，不影响分析内容。

### 9.4 迁移

菜单"显示项目文件夹"旁说明："保存并关闭项目后，复制整个文件夹即可迁移，单独复制 project.json 不包含视频。"

另一台电脑通过"打开项目文件夹"读取。先检查 schema、路径、素材及所需文件。注册到该电脑的最近列表，缓存缺失可重建；已有兼容副本可继续使用。最近列表和窗口位置属于电脑设置，不随项目迁移。

## 10. 视频兼容与后台任务

### 10.1 基线与输入范围

必须首先通过 MP4 / H.264 8-bit SDR / AAC 或无音频，最高 1080p、最高 30fps 的真实文件测试。WebM VP8 + Opus 是兼容副本的测试基线。

导入选择器允许 `.mp4 .mov .m4v .webm .mkv`；扩展名仅用于筛选，实际由 ffprobe 检查。不能承诺所有 MOV、HEVC、HDR、手机 VFR 或损坏文件直接播放。

MVP 不处理 DRM 素材；HDR 色调映射不在本版，检测到 HDR 时说明原因，请用户先转换为 SDR。高于 1080p 或 30fps、非常见音频、直接试播失败的素材进入兼容处理选择，不让用户面对无提示黑屏。

首版容量基线：单文件不超过 20GB、时长不超过 2 小时。超出范围明确提示本版限制，不开始长时间无反馈导入。限制是产品边界，不表示全部范围内都能无条件解码成功。

### 10.2 兼容副本

ffprobe 读取信息，Electron 内嵌播放器验证可播性。不能仅依赖 `canPlayType()` 声称能解码；需要验证元数据、首个可显示画面和音轨状态。

兼容副本固定为 WebM，VP8 视频、Opus 音频，长边不超过 1280、保持比例且不放大、30fps CFR、yuv420p；无音频则不创建假音轨。软件编码作为一致性后备，不依赖显卡厂商专属编码器。[S5]

副本保留完整时间范围，不剪切、不加速。时间戳起点统一到相对视频开始，但必须保留原有音视频相对偏移，不能分别把音频、视频都强行归零造成不同步。VFR 转 CFR 允许补帧/丢帧；分析仍存毫秒时间，不承诺源帧索引完全一致。

代理版本完成后验证可播、音视频同步和总时长；与标准时长差异超过 100ms 必须判为转换失败或进入显式修复流程，不直接把已有分析按比例拉伸。首尾因帧边界的小差异保留标准项目时长，播放器定位夹紧在可播放范围。

若复制后 HTML 元素时长与 ffprobe 归一化时长差异超过 100ms，先解决兼容副本问题，再启用编辑；不能让用户在错误时间域上开始分析。

转换结果写 `.partial`，只有进程成功且校验通过才改正式名称。取消、失败、磁盘满都保留完整原片和已保存分析；清理不完整副本。已有项目生成副本时不修改曲线时间。

FFmpeg 是随应用分发的后台可执行程序，不要求用户安装 Python、Node、FFmpeg 或下载编解码器。macOS arm64、macOS x64、Windows x64 分别使用对应构建；FFmpeg 的实际授权取决于编译选项，必须记录来源、配置、校验值，并提供相应许可和源代码材料；不能把任意网上下载的构建都称为 LGPL 版本。[S6]

### 10.3 缩略图

后台生成约 160×90 的缩略图，保持视频比例、空白补底；全片最多 120 张，间隔 `max(1000ms, durationMs/120)`。短视频至少生成首帧。首屏优先，未生成位置显示占位图。

缩略图按采样时间定位，放大后可复用邻近图，不要求每帧生成图片。缓存键包含源文件哈希、生成参数与应用缓存版本。缓存损坏可重建；不缓存整段解码帧。

### 10.4 任务管理

复制、校验、探测、缩略图、转码均不阻塞渲染线程。转码最多 1 个，缩略图最多 1 个；转码时暂停缩略图生成以减少争抢。

任务有状态、已完成量、错误原因和取消入口。进度百分比来自真实输出，不做假的倒计时。取消时终止对应子进程树并确认退出，避免退出应用后留下后台转码。

进程使用参数数组启动，禁用 shell 拼接；处理中文、空格、emoji、引号、非 ASCII 路径。超时采用"无进度超时"与用户取消区分，不能把合法长视频转换一律按短时间超时杀死。

复制前按源文件大小加安全余量检查空间；兼容副本按输出目标码率与时长估算，展示"估算"而非保证值，运行中仍检查磁盘写入错误。设置中显示本应用缓存大小，提供"清理缩略图缓存"，只清理 cache，不能把 source 或 playback 当作普通缓存删除。

## 11. 数据格式与不变量

### 11.1 磁盘结构

```text
项目名-短ID/
```


### 11.3 校验规则

- 项目、节点、标注、边界、段落 ID 在各自集合内唯一，引用存在。
- durationMs 为大于 0 的安全整数；曲线至少两个节点，首尾时间为 0 与 durationMs。
- 节点时间严格递增，值有限且在 0—100；控制柄满足第 5 节约束。
- 标注时间不重复，范围为 `[0,durationMs]`，文本长度符合上限。
- 边界包含且仅包含一个固定起点、终点；内部间隔满足 100ms。若全片不足 100ms，仅首尾边界可低于该间隔。
- sections 对应所有非终点边界，恰好一一对应；段落终点由下一个边界推导，避免存两份起止范围。
- 所有相对路径解析后仍在项目根目录中。
- view 非法时可回退为默认值并提示；正文结构非法时不可悄悄删除用户内容后保存。

## 12. 技术方案与模块边界

### 12.1 推荐实现路线

采用 Electron + React + TypeScript + Vite；SVG 绘制曲线、节点、控制柄和标注；HTML video 播放视频；Zod 做边界与数据校验；轻量状态库管理编辑状态；Vitest 验证纯逻辑，Playwright 做桌面端流程测试。

打包采用 Electron Forge；依赖使用实施时兼容的受支持稳定版本，锁定 lockfile，记录 Electron / Chromium / Node / FFmpeg 版本，不写浮动 latest 作为可重复构建方案。选择 Electron 的理由是两平台使用同一内嵌浏览器内核，减少依赖系统 WebView 的媒体行为差异；这是本产品的工程取舍，不代表无需实测。

不引入服务器、不使用数据库保存简单项目正文、不做 Rust/C++ 自定义解码器、不把桌面功能全部塞入网页 File API。

### 12.2 模块划分

| 模块 | 职责 | 禁止承担 |
|---|---|---|
| main/project-service | 项目创建、校验、保存、备份、锁与恢复 | React 视图更新 |
| main/media-service | ffprobe、复制哈希、兼容任务、缩略图 | 节点编辑状态 |
| main/protocol | 授权项目资源的安全流式读取 | 任意磁盘文件访问 |
| preload | 暴露最小类型化 API | 暴露完整 fs、shell、ipcRenderer |
| renderer/player | 播放状态与最新 seek 控制 | 自己累计媒体时间 |
| renderer/editor | 工具状态机、选中态、手势 | 同步磁盘 I/O |
| shared/geometry | 时间映射、插值、贝塞尔反解、局部替换 | DOM、文件系统 |
| shared/history | 内容命令、撤销重做 | 每帧视图更新 |
| shared/schema | 数据类型、验证和迁移 | 不可信路径的直接执行 |
| renderer/export | PNG 和笔记内容生成 | 视频渲染 |

### 12.3 状态分层

1. 文档状态：曲线、标注、分段等，进入历史并保存。
2. 项目视图状态：图层、缩放、播放位置等，保存但不进入历史。
3. 临时交互状态：hover、未提交笔迹、当前拖动、文本草稿，不直接写磁盘。
4. 后台任务状态：copy/probe/convert/thumb 进度与取消令牌，不混进正文。

视频每帧时间更新不能触发整棵 React 树重渲染。曲线静态几何按内容和视口缓存，播放只移动播放头。绘图与拖动通过 Pointer Events、pointer capture 处理，指针移出画布后仍能结束手势；失焦时取消未完成手势。

### 12.4 类型化接口契约

renderer 通过 contextBridge 暴露的窄接口调用 main。至少包含：

```text
projects.listRecent()
projects.create({ sourceSelectionToken, name, destinationSelectionToken })
projects.open({ projectSelectionToken })
projects.rename({ projectId, name })
projects.save({ projectId, expectedRevision, snapshot })
projects.listBackups({ projectId })
projects.restoreBackup({ projectId, backupId })
projects.removeRecent({ projectId })
projects.reveal({ projectId })
media.probe({ projectId })
media.createCompatibleCopy({ projectId })
media.rebuildThumbnails({ projectId })
media.relocateSource({ projectId, sourceSelectionToken })
tasks.subscribe(callback)
tasks.cancel({ taskId })
exports.save({ suggestedName, type, payload })
```

文件选择令牌由 main 的系统选择器或已验证的拖入入口生成；renderer 传来的任意字符串路径不自动获得访问权限。拖入真实路径通过当前 Electron 支持的 preload 文件接口获取并验证，不能依赖已废弃的非标准属性。

返回结果统一为 `ok/data` 或 `ok:false/error:{code,message,retryable}`。保存返回已落盘 revision；revision 冲突应停止覆盖并提示。大视频及图片不通过 IPC 以完整 Base64 来回复制。

### 12.5 本地媒体读取

使用受控的自定义应用协议映射 `projectId/mediaId/resourceKind`，由 main 查找已授权文件，不让 URL 直接携带任意绝对路径。注册支持媒体流的协议配置。Electron 官方说明媒体元素需要相应流式配置；具体行为须以所选版本实测。[S1]

必须正确处理 GET/HEAD、Content-Type、Content-Length、Range/206、Content-Range、越界 Range/416；拖动定位不能每次重读完整文件。可以代理可信本地文件读取实现，但必须在安装包中验证 Range 行为。

生产环境启用 `contextIsolation`、sandbox，关闭 nodeIntegration，限制 IPC 来源和参数，阻止任意远程页面导航，设置 CSP。播放器出错时不能通过关闭 webSecurity 解决。[S2]

## 13. 导出（EXPORT）

### 13.1 PNG 分析图

提供"完整视频""当前时间范围"两种范围，默认完整。固定输出宽 2400 像素，基础高 1000；包含项目名、曲线名、时间刻度、红色曲线、分段线和名称、黄色标注点及编号，不含视频画面。

底部追加编号与标题索引，按需增高，长标题换行；超过 100 条标注时 PNG 只包含前 100 条索引，并明确提示完整文字在笔记中。曲线上所有点仍显示，密集时编号可省略但不能改变时间位置。

导出不包含选择框、控制柄、播放头、悬停提示或工具栏。使用独立导出坐标计算，不截取低分辨率窗口；中文字体缺失时使用系统中文字体后备。

### 13.2 Markdown 分析笔记

包括项目名、源文件名、视频时长、曲线维度、段落起止时间和备注，以及按时间排序的全部标注标题、正文和所属段落。标注位于内部边界时归属右侧段落，位于 durationMs 时归属最后一段。

Markdown 中必须转义标题、列表和反引号等特殊内容，保证用户文本不会破坏文档结构；正文仍为纯文本。导出前先提交或取消草稿，等待项目保存完成；保存失败时说明状态，不标注输出为已保存版本。

点击导出后显示原生保存对话框；同名覆盖走系统确认。取消不算错误。写入失败保留现有输出，提示重试和另选位置。PNG 和 Markdown 导出分别工作，不强制一次生成两份。

## 16. 稳定性、性能与安装

### 16.1 性能测试目标

参考环境：Apple Silicon Mac、16GB 内存、本地 SSD；Windows 11 x64 四核或以上 CPU、16GB 内存、本地 SSD。Intel Mac 需独立记录结果，不能用 Apple Silicon 测试替代。

| 指标 | 目标与边界 |
|---|---|
| 已有项目打开 | 10 分钟基线视频、本地 SSD，在缓存有效时 3 秒内看到可操作工作台；不计首次复制/转换 |
| 曲线拖动反馈 | 1000 节点 + 200 标注 + 50 内部边界时，主流参考设备可见更新延迟目标 <50ms |
| 播放头同步 | 基线 30fps 视频正常播放时，相对呈现帧媒体时间的偏差目标 ≤100ms |
| 暂停定位 | seek 完成后，目标时间与显示画面时间在基线素材上误差目标 ≤100ms |
| 内存 | 播放 10 分钟基线视频并反复编辑 30 分钟，所有应用进程合计 RSS 目标 <1.5GB；记录外部解码/转码任务另行峰值 |
| 保存 | 分析 JSON 小于 5MB 时本地 SSD 单次保存目标 <1 秒，写入异步 |
| 长片 | 两小时素材可浏览完整时间域；缩略图和节点按需处理，不加载全片解码帧 |

这些是验收目标而不是跨硬件绝对保证。连续渲染和内存不能用演示模式估算，必须基于真实视频和实际安装包测量。超过目标应说明瓶颈与解决方案，而非放宽数值后声称达标。

### 16.2 安装与发布产物

- macOS arm64：DMG，内含 .app。
- macOS x64：DMG，内含 .app。
- Windows x64：安装器 EXE，普通用户可安装到用户目录。
- FFmpeg/ffprobe 等随平台一起打包在 resources，正确处理 macOS 执行权限、签名及 Windows 非 ASCII 路径；不能假定它们能直接在 asar 内执行。
- 发布包包含许可证、组件版本清单、安装/卸载说明、项目迁移说明。
- 卸载应用默认保留用户项目与原视频；不把整个文稿目录当作可清理缓存。

Electron 官方将打包与签名作为桌面分发环节。正式分发需要配置 macOS Developer ID 签名与公证，Windows 安装器按可用证书签名；没有证书时只能清楚标为未签名测试包，不能宣称普通下载后的首次启动体验已经完成。[S3]

证书与系统测试环境可能需要产品负责人提供；开发应先完成可构建与可测试结果，报告具体缺项，不能把证书不存在当作不做其余功能的理由。签名不等同于所有系统信誉提示必然消失。

在对应操作系统与架构上构建并运行安装包。持续集成可负责构建，但真实媒体播放、权限、拖入和恢复仍需系统端验证。只在一个 Mac 上运行开发服务器，不算完成 Windows 交付。

## 17. 建议开发顺序与每阶段完成条件

### 阶段 A：桌面与真实媒体骨架

完成两平台工程配置、原生文件选择、创建项目文件夹、复制源视频、ffprobe、真实视频播放、安全媒体读取、保存和重开。尽早产出各平台测试包。

完成条件：非开发电脑可导入一条基线视频，拖动时间线并播放，关闭重开仍能找到视频；资源读取支持 seek。

### 阶段 B：曲线核心

统一时间坐标；实现 SVG 叠加、独立图层控制、节点、直线、自动平滑、贝塞尔控制柄、自由画、局部替换、多选、撤销重做、缩放平移。

完成条件：视频、曲线和时间线严格对齐；重画只替换局部；手柄不产生回环；窗口重排与缩放不修改数据。优先写几何纯函数测试。

### 阶段 C：完整分析工作流

标注卡片、标签、标注列表、分段虚线、锁定、段落列表、项目库搜索和重命名、自动保存与故障恢复、缺失素材重新定位。

完成条件：用户可完成一次真实拉片并在重启后继续，恢复及合并操作不丢文字。

### 阶段 D：兼容、输出与稳定

兼容副本、后台任务取消、缩略图缓存、PNG 与笔记导出、中文路径、性能与异常测试、打包签名流程、安装卸载说明。

完成条件：第 18 节必测用例全部通过或明确报告阻塞项；无残留假按钮、假保存、随机生成的演示曲线或占位功能。

建议持续维护 `IMPLEMENTATION_STATUS.md`：每个需求编号的状态、实现位置、验证方式、平台结果、已知问题。该文件属于开发仓库，不放进用户项目正文。

1. 完整源码及锁定依赖，干净环境的开发和构建说明。
